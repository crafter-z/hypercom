# HyperCom

HyperCom 是一款串口调试工具。连接开发板、传感器等串口设备后，可以查看设备发来的数据、发送指令，并保存收发记录。

![HyperCom 主界面](docs/architecture/UI.png)

## 下载与安装

前往 [最新正式版下载页](https://github.com/crafter-z/hypercom/releases/latest)，在页面的 **Assets** 中选择适合自己系统的文件：

| 系统 | 下载文件 |
| --- | --- |
| Windows | `.exe` 或 `.msi` 安装包 |
| Linux | `.deb` 或 `.AppImage` |
| macOS | 对应芯片的 `.dmg`（Apple Silicon 或 Intel） |

下载后按系统提示安装并打开即可，**不需要安装开发工具或从源码编译**。Windows 10 如果提示缺少 WebView2，可从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装。macOS 目前不支持应用内自动更新，新版本请从下载页手动安装。

## 第一次使用

1. 将设备连接到电脑，在左侧串口列表找到对应端口（例如 `COM3`）。双击端口打开标签页，再点击端口旁的连接按钮。**打开标签页不会自动连接设备。**
2. 在下方「串口参数」中，按设备说明核对波特率、数据位、校验位、停止位和流控。
3. 在「发送命令」中输入设备支持的指令，选择设备要求的行尾，然后点击「发送」。中间区域的 **TX** 是发出的数据，**RX** 是设备返回的数据。

找不到端口时先点左侧「刷新」，并检查线缆、驱动和设备是否被其他软件占用；收到乱码时先核对串口参数，再尝试切换终端的文字编码。完整步骤和排查方法见 [快速入门](docs/userwiki/快速入门.md)。

## 能做什么

- **查看与整理数据**：同时打开多个串口标签页、分屏对照；搜索、筛选、复制或导出当前终端内容。可按需要切换文字、十六进制（HEX）显示及文字编码。
- **发送数据**：发送文字或 HEX 字节，设置行尾；保存常用命令、按顺序或循环发送，也可以发送文件。HEX 适合发送不能直接输入为文字的字节，例如 `AA BB CC`。
- **保存记录**：连接时可自动保存收发日志；在「设置 → 日志设置」中选择保存目录，也可以回放已保存的文本日志。
- **按设备调整界面**：给端口加备注、分组；切换亮色或暗色主题。普通收发使用 TRX 模式；需要与设备命令行交互时，可在「串口参数」中切换到 TTY 终端模式。
- **设置提醒与自动回复**：按收到的内容配置提示或回复规则；有新通知时可在底部状态栏查看。

> 关闭标签页**不会断开串口**。要停止连接，请点击端口旁的断开按钮。正式发布版不提供模拟串口；没有设备时不能用模拟端口代替真实连接。
