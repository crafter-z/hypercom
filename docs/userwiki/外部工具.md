# 外部工具

外部工具可以把某个串口交给烧录器、下载器或测试脚本使用。执行一次工具时，应用会按以下顺序处理：关闭该串口（如果它正在连接）→启动命令→把命令输出显示到该端口的终端→等待命令退出→尝试用之前的连接参数重新打开串口。

## 先配置一个工具

1. 打开「设置」→「外部工具」。
2. 点击「新建配置」。每条配置对应一个端口和一个命令。
3. 填写**配置名称**，用于在设置页识别这条配置。
4. 在「端口号」中输入端口的原始名称，例如 `COM5`。它必须与列表中的端口号完全一致；备注名不能代替端口号。串口当前未接入也可以提前配置。
5. 在「命令模板」中填写要执行的命令。使用 `{port}` 表示端口号；运行时它会被替换。例如：`stm32flash -w firmware.bin {port}`。
6. 可选填写「工作目录」。命令会在此目录中启动；留空则使用系统启动外部程序的默认目录。固件等相对路径请结合这个设置检查。
7. 点击该配置行的保存按钮（勾号，提示为「保存到配置」）。保存后配置才会用于执行；不需要等串口出现再保存。

填写端口号和命令后，页面会显示预览。预览只是把 `{port}` 换成配置中的端口号，帮助检查命令文字；不会实际启动工具。命令由操作系统的命令解释器执行：Windows 使用 `cmd /C`，其它系统使用 `sh -c`。请确认工具已安装并且命令可从该环境运行，路径含空格时按系统命令规则引用。

> 同一端口如果保存了多条配置，执行时使用列表中第一条匹配端口号的配置。建议每个端口只保留一条，避免运行了意外命令。

## 从哪里启动

配置保存后，可以从以下位置启动同一项操作：

- 左侧串口列表中右键端口 →「执行外部工具」。
- 已打开的标签页右键 → 工具菜单中的「执行外部工具」。
- 分组头右键 →「整组执行外部工具」。

端口没有匹配配置时，点击「执行外部工具」不会启动命令，而是直接打开「设置 → 外部工具」供你配置。单个端口的入口只按端口号查找配置，不会替你检查命令是否为空；请务必填写非空命令，否则可能启动一个没有实际工作的命令。工具正在运行时，端口右键菜单会显示「终止外部工具」；点击它可以请求停止该进程。

## 运行时会发生什么

- 若端口已连接，运行前会先关闭它；工具独占串口期间不要在其它程序中同时打开同一端口。
- 命令中的 `{port}` 会在真正运行前替换为端口号，例如 `COM5`。工具的 stdout 和 stderr 会逐行写入该端口的终端，并标记为工具输出；二进制或不按行输出的程序可能不会按预期显示。
- 命令正常返回 0 时，终端会显示「[工具] 进程正常退出 (code 0)，串口已重开」；其它退出码也会显示。终止进程会让工具以非 0 结果结束，具体退出码由系统决定。
- 工具退出后，应用会立即尝试重开端口，并使用该端口最近一次成功连接的参数（波特率、数据位、校验、停止位、流控等）。因此，想要工具退出后自动恢复连接，建议先用目标参数成功连接一次。
- 如果端口从未成功连接、设备已拔出，或重开失败，工具本身的结果仍会显示，但串口不会变成已连接；请检查设备、端口号和连接参数后手动重试。重开失败时端口状态会显示为错误。
- 整组运行会跳过已经在运行工具的端口；单个端口运行时请不要重复点击「执行外部工具」。

## 整组执行

1. 先把端口放入同一个分组，并为需要执行的每个端口分别保存工具配置。
2. 右键分组头，选择「整组执行外部工具」。
3. 对话框会统计组内「已配置」和「未配置」的端口。只有端口号匹配且命令不为空的配置才算已配置。
4. 若存在未配置端口，可选择「去配置未配置的串口」打开设置页，或选择「仅运行已配置」。如果组内没有任何已配置端口，只能关闭对话框或去配置。
5. 运行已配置端口时，各端口的工具会同时启动；一个端口失败不会取消其它端口。已在运行工具的端口会跳过。

整组执行不会替未配置端口猜测命令，也不会把备注名当作端口号。请逐个检查配置中的端口号和命令。
