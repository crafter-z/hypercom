# 外部工具

外部工具功能用于把串口与外部命令行工具（如烧录器、固件下载工具）对接，实现「关闭串口 → 运行工具 → 工具退出 → 重开串口」的自动化闭环。

## 使用场景

例如用 `stm32flash` 烧录固件、运行 `esptool`、执行自定义测试脚本。工具执行时串口自动关闭交给工具；工具退出后串口立即重开，确保捕获下位机 reset 后的第一帧输出。

## 配置外部工具

「设置 → 外部工具」。

- **新建配置**：创建一条端口工具映射。
- **端口号**：绑定到哪个串口（可不要求串口当前存在，预先配置好）。
- **命令模板**：命令行工具调用。占位符 `{port}` 会被替换为实际端口名。
  - 例：`stm32flash -w firmware.bin {port}`
- **工作目录**：工具运行目录（留空使用默认）。
- **预览**：实时预览 `{port}` 替换后的完整命令。
- 配置右下角「保存工具配置」持久化。

> 可预先配置多个端口的工具，串口未接入时也无妨。

## 触发运行

配置好工具后，通过以下入口运行：

- **侧边栏串口右键** →「执行外部工具」。
- **标签页右键（工具菜单）**：与侧边栏同源。
- **分组头右键** →「整组执行外部工具」。

### 整组执行外部工具

对分组内多个串口整组运行工具：

- 打开对话框后，列出组内**已配置**与**未配置**的串口。
- **去配置未配置的串口**：跳转到外部工具设置页补齐。
- **仅运行已配置**：并行运行已配置端口的工具（跳过运行中的端口，单端口失败不中断整组）。
- 若组内没有已配置工具，会提示。

## 运行控制

- 工具运行期间，串口连接会自动关闭，结束后自动重开。
- **终止外部工具**：右键菜单可随时终止正在运行的工具进程。
- 工具输出以 `[工具]` 行形式写入终端，退出码也会显示（如 `[工具] 进程正常退出 (code 0)，串口已重开`）。
