# 规则与协议

HyperCom 提供四类增强工具：**语法高亮**、**命令集**、**协议解析**、**条件触发**。它们都在「设置」弹窗中配置，并按用户自定义的规则作用于收发数据。

## 语法高亮规则

「设置 → 语法高亮规则」。

- **规则集**：一组高亮规则的集合。每个规则集可单独启用；多个启用规则集可同时生效。
- **规则**：一条匹配规则指定——
  - **匹配模式**（正则表达式或关键词）
  - **是否正则**
  - **颜色、加粗、斜体**
- **用法**：接收数据时，命中的内容按规则着色，便于快速识别关键数据（如错误码、关键词）。

- **新建规则集** / **添加规则** / **删除规则**。
- 规则集右上角「保存到配置」持久化。

## 发送命令规则集

「设置 → 发送命令规则」。

- **命令集**：一组可自动顺序 / 循环发送的命名命令集合。
- **每条命令**包含：名称、顺序、延时 (ms)、发送类型（字符串 / HEX）、命令内容、行尾。
- **循环**：命令集可开启循环发送；**两轮之间的间隔 (ms)** 可设置。
- **重复轮数**：`0` = 跟随「循环」开关；`>0` = 发送指定轮数后停止。

- 配置好命令集后，在**操作面板**选择它即可一键顺序执行；也可通过**快捷发送条 / 命令面板**逐条发送（见 [数据收发](数据收发.md)）。

## 协议解析模板

「设置 → 协议解析」。用于按帧结构解析接收数据并给字段着色。

- **模板**：定义一套帧结构规则，每个串口可绑定一个协议模板。
- **帧结构**：
  - **帧头 (Hex)**：如 `AA BB`（可为空）
  - **长度字段**：长度偏移、长度字段大小（1 / 2 字节）、字节序（小端 / 大端）、长度修正
  - **帧尾 (Hex)**：如 `0D 0A`（可为空）
  - **校验和**：算法（无 / Sum8 / XOR / CRC-8）与偏移（`0` = 自动，帧尾前）
- **字段颜色**：帧头、长度、负载、校验、帧尾可分别着色。
- **启用模板**：在终端工具栏「协议」下拉里选择模板；绑定后收到的帧自动解析并着色字段。

> 协议解析适用于**TRX**模式（有明确的帧结构）；TTY 字节流模式不做解析。

## 条件触发

「设置 → 条件触发」。设置「模式匹配 → 动作」的规则，收到匹配数据时自动执行。

- **匹配模式**：`包含` / `精确匹配` / `正则表达式` / `HEX 字节`。
- **触发动作**：
  - **弹出提示**：显示一条粘性通知（附端口与规则上下文）。
  - **自动回复**：向串口发送**动作内容**（可切换 HEX 格式发送）。
- **指定串口**：规则可绑定到指定端口；留空 = 全部串口。
- 每条规则支持一定防抖与自动保存（编辑后 300ms 内自动落盘）。

> 条件触发可从「串口来源」发出通知——触发的告警、断线等 toast 会附带串口号，在通知中心可查看（见 [通知中心](#通知中心)）。

## 通知中心

状态栏右侧的铃铛图标打开**通知中心**。它收集来自串口的提示（触发告警、断线、发送目标关闭、重连失败等）。

- 每条通知显示**串口 chip** 与 **HH:MM:SS 时间戳**。
- 超过 5 条时进入溢出队列，不丢弃，可查看/逐条关闭/清空。
- `durationMs = 0` 的通知（如触发告警）是**粘滞**的，不会自动消失。
