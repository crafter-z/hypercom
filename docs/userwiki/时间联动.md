# 时间联动与多轨回放

一个设备有多个串口、或同时比较多个设备时，可以把多个视图加入时间联动组。在一个成员里浏览到某个时间，其他成员定位到该时间附近的记录。联动的是**时间锚点**，不是像素或滚动百分比；没有对应输出的成员会停在最近记录并显示差值，不会伪造空白日志。

## 创建与管理组

1. 打开需要比较的 TRX 终端、支持时间接口的插件或回放轨道，按需要分屏。
2. 点击工具条的链条图标，或在标签右键选择「时间联动…」。
3. 输入组名、勾选参与视图并点击「创建联动组」；也可以选择「加入已有组」。每个视图只能属于一个组，不需要指定永久主从。
4. 标签用链条、G 编号与辅助颜色标识组；工具条仅保留紧凑链条图标，悬停可查看组编号，不重复占宽。再次点击链条可勾选或取消成员，点击「保存成员」生效。
5. 拖动方式、时间偏移、事件对齐、对齐状态和解散组统一收在管理窗口的「高级设置」，默认折叠。

新建组从发起视图的当前中心记录开始浏览；加入组不会抢走正在操作的成员的驾驶权。切换焦点或普通点击行不会驱动组。

## 拖动策略

| 策略 | 行为 |
|---|---|
| 自动 | 默认。根据成员能力、近期定位耗时和前台帧压力决定预览，慢成员降为松开后对齐 |
| 拖动时联动 | 优先连续预览，但仍有节流、取消和背压；不强迫慢插件无限重画 |
| 松开后对齐 | 拖动期间其他成员保持原位，结束后定位到最终时间 |

拖动时不表示所有成员已经到位，可在「高级设置」查看对齐状态。连续联动也只应用最新目标，不回放中间请求。响应慢的成员不会阻塞其他成员；最终未对齐会显示状态，而不是把请求已发出当作成功。

某些平台的原生滚动条无法可靠报告按下意图。这时不要认为拖动一定会广播，可在面板使用**「按当前位置对齐」**可靠提交。Ctrl+滚轮只改字号，横向滚动不驱动时间组。

## 时间基准与偏移

默认比较采集侧时间，不是设备内部硬件时钟，也不提供 NTP 或漂移校正。

- **原始时间**：同一宿主采集的实时来源可以直接比较。
- **事件 T+0**：在每个来源找到同一个事件，把各自当前中心设为 T+0，适合比较不同采集日期或不同设备的启动过程。
- **常量偏移**：正偏移把源事件放到更晚的组时间，负偏移放到更早。只改映射，不改原始日志。

同源 raw 与插件共用源映射，不能分别校成两个不同时间。跨时间域或回拨时段需明确选择/确认，不会偷偷把昨天的数据搬到今天。

## 浏览、实时与本地保护

- 新建组保留发起视图原有的图钉（滚动锁定）意图：原本已开启且成员支持实时跟随，就继续整组跟随，不会因开启联动而停住；原本未开启则保持历史浏览。图钉开启后整组跟随实时，关闭后整组保持浏览，不再有单独的「返回实时」按钮。
- 图钉亮态表示整组正在跟随；浏览历史会停止整组跟随，滚到尾部或跳到底部不会自动开启。回放、实时与回放混组或时钟不兼容的组不提供实时跟随。
- 退出组保持当前位置，之后需要用户自己重新开启独立图钉。
- 搜索框可与图钉同时使用，打开或输入关键词不会停止跟随；跳到搜索结果时才停止整组跟随并联动定位。保持搜索框打开也可以再次点图钉恢复跟随，关闭搜索不会自动复锁。过滤、编码、HEX 切换仅影响本视图。
- 暂停显示仍接收数据，只冻结可见上界；不会为了对齐而擅自恢复。
- 有效文本选区暂缓外部定位；清除后只应用最新目标。需要独立浏览某个视图时，可在管理窗口取消勾选该成员并保存。
- 断线保留已有历史，不拖停健康成员；清屏只清本来源。范围不足、无时间、被过滤、加载或响应慢都在结果区显示。
- 关闭标签不会断开串口或停止后端日志。

首版只支持主窗口中的 TRX、主动适配的插件和回放标签。TTY、终端弹出窗和未适配插件暂不参与，不会暗中驱动隐藏原始终端。联动不保证所有视图逐行水平排齐，也不保证任意百万行、多插件组合 60fps。

## 多轨历史回放

在操作面板选择「导入历史日志」，不需要真实串口标签。确认轨道、分片顺序、文本/HEX 格式和记录机 UTC 偏移后，每轨打开独立只读标签。

- 完整历史可搜索，播放只移动共同游标，不反复追加记录。
- 多轨共用组时钟，支持暂停、倍速和定位；保留真实长间隔，轨道提前结束不会截断其他轨道。
- 手动导航立即暂停播放，继续需显式点击。实时与回放混组只用于浏览，并需确认时间映射。
- 无可靠时间显示 `—`；全无时间的轨道只独立查看。回拨日志先选择时段。
- 回放不会连接设备、发送 TX、触发自动回复/告警或污染实时流量。

首版仅 UTF-8 文本/HEX 文本，最多 16 文件、单文件 32 MiB、总文件 64 MiB、500,000 记录、192 MiB 解码内存；超限拒绝，不静默截断。原始 binary/GBK 不在首版导入范围。

工作区恢复默认浏览/暂停，不自动连接、读取历史文件或播放。历史来源需要重新原生选择并核对文件指纹，缺失或变化会提示重新确认。详细文件与格式说明见[日志记录](日志记录.md)。
