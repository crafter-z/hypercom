# 快速入门

本页帮助你不看任何文档，在 5 分钟内完成第一次收发。

## 1. 连接串口

1. 用 USB 转串口线（或开发板的板载串口）连接电脑。
2. 打开 HyperCom 后，左侧**串口管理**列表会自动刷新，显示检测到的串口。
3. 点击串口右侧的「连接串口」按钮（或右键菜单里选「连接串口」），状态点变绿即为连接成功。

> 检测不到设备？插入 USB 转串口模块后列表会自动刷新；也可以点击工具栏「刷新」按钮手动刷新，或点「开启模拟模式」体验（见 [串口管理](串口管理.md)）。

## 2. 打开一个标签页

连接到串口后，终端默认在右侧打开一个标签页并显示数据。若没有自动打开：

- 双击左侧列表里的某个串口；或
- 右键 → 「在标签页中打开」。

## 3. 发送数据

在底部**操作面板**的「发送命令」区：

1. 在输入框输入要发送的内容。默认按 `Enter` 立即发送。
2. 若输入的是字节流，切换到 **HEX** 模式（如 `AA BB CC`）。
3. 选择行尾（换行符）——`\r\n`（CRLF）、`\r`（CR）、`\n`（LF）或「无」。
4. 点击「发送」，或直接按 `Enter`。

收到的数据实时显示在终端里，接收到的内容会以你选择的编码（默认 UTF-8）解码。

## 4. 常用界面概览

| 你想做的事 | 去哪里 |
| --- | --- |
| 连接 / 断开 / 重试连接 | 操作面板左上角按钮 |
| 改变端口参数（波特率/数据位/校验…） | 操作面板「串口参数」区 |
| 发送字符串或 HEX 字节 | 操作面板「发送命令」区 |
| 循环发送、批量命令 | 快捷发送 / 命令面板（见 [数据收发](数据收发.md)） |
| 查看 / 搜索终端内容 | 标签页上方的过滤 / 搜索栏（见 [终端显示](终端显示.md)） |
| 保存 / 回放日志 | 操作面板「日志」区（见 [日志记录](日志记录.md)） |
| 调整显示颜色 / 主题 / 语言 | 标题栏「设置」→（见 [设置](设置.md)） |

## 5. 快速功能一览

- **高亮规则**：为关键数据自动着色（正则 / 关键词匹配）。
- **分屏多标签**：上下 / 左右分屏，标签页可拖拽跨分屏。
- **日志记录**：连接即自动落盘，支持分片存储与导出。
- **协议解析**：按帧结构自动解析并着色字段。

## 6. 遇到问题

- **无法连接 / 端口被占用**：确认没有其他软件占用该串口。
- **收不到数据**：检查波特率与设备一致、接线（TX/RX 交叉）、是否开启了流控。
- **乱码**：切换终端右上角「编码」（UTF-8 / GBK / ASCII 等）与设备一致。

更多细节见 [串口管理](串口管理.md) 与 [数据收发](数据收发.md)。
