# 快速入门：连接设备并收发数据

没有设备也可以先熟悉界面，但正式发布版不提供模拟串口；下列步骤以真实串口为例。

## 1. 找到并打开端口

1. 把 USB 转串口线或带串口的开发板接到电脑，打开 HyperCom。在左侧列表找到设备端口，例如 `COM3`。不确定端口号时，可先拔下设备记住列表，再插回观察新增的端口。
2. **双击端口**，在中间打开它的标签页。打开标签页并不等于连接设备。
3. 点击端口右侧的连接按钮；也可以选中标签页后，点下方操作面板顶部的「打开串口」。连接成功后，端口状态点变绿。连接按钮只负责连接或断开，不会因为连接成功而自动新建标签页，所以建议先双击打开标签页。

找不到端口时，点左侧工具栏「刷新」；仍找不到，请检查线缆、设备驱动和系统是否识别到该设备。连接失败时，先关掉可能占用同一端口的其他串口软件。

## 2. 核对通信参数

选中刚打开的标签页，在下方「串口参数」中检查**波特率、数据位、校验位、停止位、流控**。它们需要与设备要求一致；不确定时查设备说明书。参数不匹配可能表现为乱码或收不到数据。

## 3. 发一条数据

1. 在下方「发送命令」输入框输入设备能识别的命令，例如设备手册里的查询指令。
2. 选择设备要求的行尾：**无**、**CR (`\r`)**、**LF (`\n`)** 或 **CRLF (`\r\n`)**。有的设备必须收到换行才会回应。
3. 点击「发送」或按 `Enter`（默认设置）。要输入换行，用 `Shift+Enter`；也可以在设置中改成 `Enter` 只插入换行。

要直接发送字节，可切到 **HEX**，输入如 `AA BB CC`。HEX 必须是完整的两位一组的字节；写错或少半位不会发送。详见 [数据收发](数据收发.md)。

收到的数据会显示在中间终端。**TX** 表示发出去的内容，**RX** 表示设备回来的内容；有的设备不会自动回显，也不会对所有命令作答。

## 4. 没有反应怎么办

- **端口未连接**：检查状态点是否为绿色、标签页是否选对；连接与打开标签页是两件事。
- **发送后没有 RX**：核对设备手册中的命令和行尾；检查设备供电、接线、波特率及流控设置。
- **收到乱码**：先核对波特率等通信参数，再在终端顶部「编码」中尝试设备使用的 UTF-8、GBK 等编码。
- **想保留数据**：连接时可自动写日志；存放位置和回放方式见 [日志记录](日志记录.md)。
