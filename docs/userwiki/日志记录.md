# 日志记录

HyperCom 默认**连接即自动落盘**——RX/TX 数据实时写入日志文件，无需手动开启。本页说明日志的存储、格式、分片、回放与导出。

## 自动落盘

- 每个串口连接期间，收发的数据自动写入日志文件（**RX 方向**按行组装，**TX 方向**直接写入）。
- 日志文件的路径由「设置 → 日志设置」配置，默认存到日志存储目录。
- 数据为空的行不会落盘；关闭串口时若文件为空会自动删除。

## 操作面板里的日志操作

在每个端口的**操作面板**「日志」区（或随标签绑定）：

| 按钮 | 作用 |
| --- | --- |
| 另存为 | 把当前端口的日志另存为一个文件 |
| 打开文件 | 直接打开该端口的日志文件 |
| 目录 | 打开日志存储目录 |

## 回放日志

终端工具栏的「回放日志」按钮可以从日志文件回放历史数据到终端，用于复盘。

- 选择要回放的日志文件，设置**回放倍速**（可选最快）。
- 点击「停止回放」随时结束。
- 回放内容写入当前打开的终端标签页。

## 日志设置（设置 → 日志设置）

| 设置项 | 说明 |
| --- | --- |
| 自动保存日志 | 连接即自动落盘（默认开启） |
| 每次打开串口时新建日志文件 | 开启后每次打开串口新建一个文件，不续写已有文件（默认关闭，保持续写） |
| 日志存储目录 | 日志保存的目录；点击「浏览…」选择 |
| 文件名格式 | 可用变量：`[com]`（端口号）`[datetime]`（日期时间）`[date]`（日期）`[time]`（时间） |
| 日志格式 | 字符串 / 十六进制 / 二进制 |
| 日志编码 | ASCII / UTF-8 |
| 开启分片存储 | 超过分片大小时自动拆分为多个文件 |
| 分片大小 (MB) | 分段文件的阈值 |
| 日志行包含时间戳 | 每行前缀 `[时间]` |
| 日志行包含 RX/TX 方向标记 | 每行前缀 `RX| ` / `TX| ` |
| 日志子目录 | `不区分` / 按日期分文件夹（`YYYY-MM-DD`）/ 按串口号分文件夹 |

> **子目录说明**：选择「按日期」或「按串口号」，日志会按对应维度文件夹存放，便于长期整理。
>
> **更改目录**：修改日志存储目录时会弹窗提示，可选择「仅切换目录」或「迁移旧日志并切换」（把旧日志文件搬到新目录）。

## 日志分片

- 开启分片后，单个日志文件达到**分片大小**会自动拆分为新文件。
- 新文件名在原文件名后追加序号（如 `log-1.log`、`log-2.log`）。

## 导出终端内容

在终端右键菜单可把当前显示内容导出：

- **导出为 TXT**
- **导出为 CSV**

> 也可用「另存为」把整个日志存为文本。
