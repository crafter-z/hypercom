# 数据收发

本页说明如何向串口发送数据，以及快捷发送、命令面板、循环发送、文件发送等功能。

## 手动发送

在底部**操作面板**「发送命令」区：

1. **输入内容**：在输入框输入要发送的字符串，或切换到 **HEX 模式**输入十六进制字节（如 `AA BB CC`）。
2. **选择行尾**：
   - `\r\n`（CRLF）
   - `\r`（CR）
   - `\n`（LF）
   - 无（不追加换行）
3. **发送**：点击「发送」按钮，或按 `Enter`。

> - **发送后清空** 勾选后，每次发送后清空输入框。
> - **回车行为**：默认 `Enter` 发送、`Shift+Enter` / `Ctrl+Enter` 换行。可在「设置 → 通用设置」改为「回车键插入换行（而非发送）」，此时只能点「发送」按钮发送。
> - **端口守卫**：如果端口未连接，发送会提示「串口未连接，无法发送数据」，不会发送。

### HEX 模式

- `AA BB CC` 发送字节 `AA BB CC`。
- `AA,BB,CC`、`AABBCC` 等也可解析（支持常见分隔）。
- 输入非法 HEX 时按规范解析，无法解析的部分会被跳过并提示。

## 快捷发送条 / 命令面板

在「发送命令」区下方是**快捷发送条**。它按你配置的**命令集**把命令显示为可一键发送的「药丸」。

- **点击药丸**立即发送对应命令。
- **首槽「命令面板」按钮**：打开独立发送面板。
- 快捷发送条宽度自适应，可按面板宽度显示尽量多的命令。

### 命令面板（独立窗口）

点击「命令面板」按钮（或侧边栏/工具栏的「打开独立发送面板」）弹出独立面板，可更自由地批量发送命令。有两种模式：

#### 命令列表模式
- **命令集**：选择要使用的命令集；**编辑命令集** 跳转配置页。
- 点击命令立即发送；点击「修改」可在面板内编辑名称、行尾与内容。
- **发送到**：选择目标串口（底部提示灯跟随真实连接状态：绿 = 已连接，灰 = 断开）。

#### 文本模式
- 每行一条命令，支持任意行数；执行时每行作为独立命令发送。
- **执行当前行** / **执行当前行并移至下一行**：逐行执行。
- **顺序完整执行**：从首行顺序执行全部。
- **从当前位置执行**：从当前光标所在行开始执行。
- **完整循环执行**：循环执行整份列表；**停止** 可随时结束。

## 循环发送

循环用于周期性发送同一组命令。两种方式：

1. **操作面板命令区**：选择命令集后点「开始循环」，按命令集里每条的**延时**和**轮次间隔**循环发送；点「停止发送」结束。
2. **命令面板文本模式**：「完整循环执行」+「停止」。

> 循环发送绑定启动它的**端口**，多端口可各自独立循环。循环发送属于静默发送，端口未连接时不会打扰你。

## 发送文件

点击发送命令区「发送文件」按钮，选择文件后按当前串口参数发送文件内容（适合发送固件 bin / 测试数据）。

- 传输过程中文件按钮变为**取消**按钮，可随时取消。
- 发送结束会显示「文件已发送」，进度条清空。

## 发送历史与回显

- 每次发送的内容会以 **TX** 行写入终端（TRX 模式本地回显，便于对照）。
- 发送同时记录到发送历史与日志（见 [日志记录](日志记录.md)）。
- 发送与接收通过统一管线保证时序：**发送回显前会先排空已聚合的接收队列**，避免批量接收的数据追上发送顺序。

## 发送配置（设置 → 显示与交互）

- **默认换行方式**：新建会话时默认追加的行尾。
- **发送提示前缀**：默认留空；如需在 TX 行前面附加提示文字可在此设置。
