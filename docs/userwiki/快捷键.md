# 键盘快捷键

按 `Ctrl + /`（或标题栏/帮助入口）打开快捷键帮助弹窗。以下快捷键适用于未聚焦在输入框时的全局操作。

## 全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + L` | 清空当前终端 |
| `Ctrl + K` | 连接 / 断开当前端口 |
| `Ctrl + B` | 切换侧边栏显示 |
| `Ctrl + /` | 显示 / 隐藏快捷键帮助 |
| `Ctrl + F` | 聚焦终端搜索（由终端标签页本地处理） |
| `Esc` | 关闭顶层弹窗 / 对话框 |

> - 快捷键使用 `Ctrl`（macOS 上为 `Cmd`）。
> - 焦点在**输入框 / 文本域 / 下拉框**等表单元素时，全局快捷键不生效（`Ctrl+L / K / B / /`），避免干扰输入；`Esc` 始终可用。

## 终端内搜索快捷键

在终端搜索栏打开时：

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 下一个匹配 |
| `Shift + Enter` | 上一个匹配 |
| `Esc` | 关闭搜索 |
