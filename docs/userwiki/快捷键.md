# 键盘快捷键

快捷键帮助有两种打开方式：点击标题栏的键盘图标，或按 `Ctrl+/`（macOS 通常使用 `Cmd+/`）。下面的快捷键在光标没有停在输入框、文本框或下拉框里时生效。

## 常用操作

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+L` | 清空当前终端的显示内容 |
| `Ctrl+K` | 连接或断开当前标签页对应的端口 |
| `Ctrl+B` | 显示或隐藏左侧串口列表 |
| `Ctrl+/` | 打开或关闭快捷键帮助 |
| `Esc` | 关闭当前最上层的搜索栏、弹窗或对话框 |

清空终端只清除当前画面，不会删除已经写入磁盘的日志，也不会断开串口。

## 终端搜索

先点击终端，再使用：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+F` | 打开或关闭当前终端的搜索栏 |
| `Enter` | 跳到下一个匹配项（搜索栏已打开时） |
| `Shift+Enter` | 跳到上一个匹配项 |
| `F3` | 打开搜索并跳到下一个匹配项 |
| `Shift+F3` | 打开搜索并跳到上一个匹配项 |
| `Esc` | 关闭搜索栏 |

## 使用时注意

- Windows / Linux 使用 `Ctrl`；macOS 使用 `Cmd`。
- 在输入框、文本框、下拉框或其他可编辑区域输入时，全局快捷键不会抢走你的按键。搜索栏里的 `Enter`、`Shift+Enter` 和 `Esc` 仍按搜索功能处理。
- 如果快捷键没有反应，先点击终端或空白区域，把焦点从输入框移开。
