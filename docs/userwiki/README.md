# HyperCom 使用手册

HyperCom 可以连接串口设备、查看设备发来的数据，也可以向设备发送文字或十六进制数据。不知道从哪里开始？先看 [快速入门](快速入门.md)。

![HyperCom 主界面](../architecture/UI.png)

## 界面怎么找

- **左侧串口列表**：找设备、连接或断开、给端口加备注。双击端口可打开标签页。
- **中间终端**：看收到和发出的数据；可切换标签、搜索、筛选和分屏。
- **下方操作面板**：调整当前端口的串口参数、发送数据；顶部还有连接、清屏和日志操作。
- **右上角**：打开设置、关于和快捷键帮助。
- **底部状态栏**：查看连接与收发状态；点铃铛查看通知。

## 页面里常见的词

- **端口 / 串口**：电脑识别到的设备接口，例如 Windows 的 `COM3`。
- **接收（RX）**：设备发给电脑；**发送（TX）**：电脑发给设备。
- **HEX**：用十六进制表示字节，例如 `41 42` 是两个字节；适合发送非文字数据。
- **TRX**：按行显示收发内容的普通模式，适合大多数调试场景。
- **TTY**：适合与设备命令行交互的终端模式，能显示光标和终端控制效果。两种模式的区别见 [终端显示](终端显示.md)。
