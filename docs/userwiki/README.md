# HyperCom 用户手册

本手册面向使用 HyperCom 调试串口设备的**最终用户**（嵌入式开发、硬件测试等场景）。

## 界面总览

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏   HyperCom                      设置  关于  最小化 最大化 关闭 │
├────────────┬───────────────────────────────────────────────────┤
│ 侧边栏      │  主显示区（多标签页 / 多分屏）                        │
│ 串口管理     │  ┌── 标签页1 ──┐ ┌── 标签页2 ──┐                    │
│ · 搜索框     │  │   终端视图   │ │   终端视图   │                    │
│ · 工具栏     │  │            │ │            │                    │
│ · 串口列表   │  └────────────┘ └────────────┘                    │
│   (分组)    ├───────────────────────────────────────────────────┤
├────────────┤ 操作面板                                           │
│            │  串口参数   发送命令   日志                          │
├────────────┴───────────────────────────────────────────────────┤
│ 状态栏   连接数   收发速率   CPU/内存  通知中心     ↕↓ 收发速率       │
└────────────────────────────────────────────────────────────────┘
```

主要区域：

| 区域 | 说明 |
| --- | --- |
| 标题栏 | 应用标题、设置入口、关于、窗口控制（自定义，无系统边框） |
| 侧边栏 | 串口管理：搜索、刷新、排序、分组、隐藏、备注名、模拟模式 |
| 主显示区 | 多标签页终端，支持左右 / 上下分屏 |
| 操作面板 | 串口参数设置、发送命令、日志实时查看 |
| 状态栏 | 连接数量、收发速率、CPU / 内存负载、通知中心 |

## 术语

| 术语 | 含义 |
| --- | --- |
| 串口 / 端口 | 操作系统枚举的串行通信设备，如 `COM1`、`/dev/ttyUSB0` |
| TRX | 传统行级文本终端模式，按「行」收发显示 |
| TTY | 完整交互式终端模式（基于 xterm.js），支持 ANSI / 光标 / 备用屏幕 |
| RX | Receive，接收方向（设备 → 电脑） |
| TX | Transmit，发送方向（电脑 → 设备） |
| 帧 | 协议解析中的一次完整数据单元，含帧头 / 长度 / 负载 / 校验 / 帧尾 |
| 命令集 | 一组可顺序 / 循环发送的命名命令集合 |
