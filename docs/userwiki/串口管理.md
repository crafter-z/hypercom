# 串口管理

左侧**串口管理**侧边栏是连接、组织串口设备的核心区域。它每 3 秒自动刷新一次，支持搜索、排序、分组、隐藏、备注名，以及调试专用的模拟端口。

## 串口列表

- **自动刷新**：应用每 3 秒重新枚举系统串口，插入 / 拔出设备会自动更新。
- **连接状态**：每个串口有一个状态点——
  - 灰 = 未连接
  - 绿 = 已连接
  - 黄 = 连接中
  - 红 = 错误
- **类型徽标**：`SIM`（模拟端口）、`VCP`（USB 虚拟串口）等。
- **拖动排序**：直接拖动串口可调整显示顺序。

## 工具栏按钮

| 按钮 | 作用 |
| --- | --- |
| 搜索框 | 按名称 / 备注名快速过滤串口 |
| 刷新 | 手动重新枚举串口 |
| 按端口号排序 | 按端口号自然排序（`COM1 < COM2 < COM12`，数值比较） |
| 打开全部 | 打开所有串口对应的标签页 |
| 关闭全部 | 关闭所有串口对应的标签页 |
| 显示 / 隐藏已隐藏 | 切换是否显示被隐藏的串口 |
| 更多操作 | 其他工具 |

## 右键菜单（单个串口）

- **连接串口 / 断开连接**：建立或断开连接。
- **在标签页中打开**：打开该串口的终端标签页。
- **设置备注名**：给串口起一个易记的名字，显示在列表中。
- **隐藏此串口 / 取消隐藏**：在列表中隐藏不常用的串口。
- **执行外部工具**：运行绑定的外部工具（如烧录）。
- **配置外部工具…**：跳转到外部工具配置页。
- **终止外部工具**：停止正在运行的外部工具。
- **移入分组「{{name}}」/ 新建分组并移入 / 移出分组**：管理分组归属。

## 分组管理

分组用于组织多个串口，便于整组连接 / 断开或整组执行外部工具。

- **新建分组**：点击列表底部「新建分组」。
- **重命名**：双击分组名，或右键 →「重命名分组」。
- **连接整组 / 断开整组**：分组头右键菜单。
- **整组执行外部工具**：分组头右键 →「整组执行外部工具」（见 [外部工具](外部工具.md)）。
- **删除分组**：右键 →「删除分组」。
- **拖拽串口**：把串口拖入 / 拖出分组调整归属。

> 分组及串口排序保存在配置文件里，下次启动自动恢复。

## 备注名

每个串口可以设置一个**备注名**，便于识别（例如「STM32 调试口」「GPS 模块」）。右键串口 →「设置备注名」输入即可。备注名会显示在串口列表中，若设置了备注名，它通常替代原始端口号作为标签页标题。

## 模拟端口（调试）

用于在没有真实硬件时体验和测试。

- **SIM（Loopback）：** 点击工具栏「开启模拟模式」（烧杯图标）。它会生成一个虚拟串口，向它发送内容会原样回显，可用于测试收发、高亮、协议解析等。
- **GIT:BASH 模拟终端：** 调试专用，启动本机 Git Bash 的一个伪终端（仅开发构建可见）。用于测试 TTY 终端模式的完整交互能力。

> 模拟端口仅支持调试构建，正式发布版不提供。
