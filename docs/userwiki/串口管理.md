# 串口管理

左侧的**串口管理**列表用于查找、连接和整理串口。列表通常每 3 秒自动刷新一次；也可以点击刷新按钮立即重新读取系统中的串口。

## 找到并打开串口

### 列表中的信息

- 串口号（例如 `COM3`）始终显示；设置了备注名时，备注名会同时显示。
- 状态点表示当前状态：灰色=未连接、绿色=已连接、黄色=连接中、红色=错误。
- `SIM` 是模拟串口，`VCP` 是 USB 虚拟串口等类型标记。
- 搜索框不在工具栏按钮中，而在列表下方；输入串口号或备注名即可过滤，搜索不区分大小写。

连接串口有三种入口：

1. 点击串口行右侧的播放/停止按钮。
2. 右键串口，选择「连接串口」或「断开连接」。
3. 点击工具栏的「打开全部」或「关闭全部」，批量连接或断开列表中的串口。

连接成功后，端口状态点变绿；如果该端口已经有标签页，标签页会继续显示。连接操作不会替你新建标签页，所以第一次使用时请先双击串口行打开（或右键 →「在标签页中打开」）。断开连接也不会关闭标签页，标签页中的历史内容仍可查看，之后可以重新连接。双击串口行只能打开或激活标签页，不会连接端口。

> 批量连接/断开会按顺序处理端口，而不是同时操作。端口较多时请等待状态更新完成。

## 工具栏和排序

工具栏上的按钮从左到右可能包括：

- **烧杯图标**：开启或关闭 `SIM:Loopback` 模拟串口（仅调试版本，见下文）。
- **终端图标**：开启或关闭 `GIT:BASH` 模拟终端（仅调试版本，见下文）。
- **刷新**：立即重新枚举串口。
- **打开全部 / 关闭全部**：连接所有当前列出的端口，或断开当前已连接的端口。
- **更多操作**：打开「显示/隐藏已隐藏串口」和「按端口号排序」。

点击「按端口号排序」会立即按自然顺序重排，例如 `COM1`、`COM2`、`COM12`。这是一次性排序，不是会一直生效的排序开关；之后仍可拖动端口调整顺序，下一次点击排序才会再次按端口号重排。

## 右键菜单

右键单个串口可以使用以下操作：

- **连接串口 / 断开连接**：切换该端口的连接状态。
- **设置备注名**：输入便于识别的名称。备注名会显示在列表中，并会作为标签页标题的一部分（标题仍包含原始串口号）。
- **在标签页中打开**：创建或激活该端口的标签页。
- **执行外部工具**：运行该端口匹配的外部工具；没有匹配配置时会直接打开「外部工具」设置页，请先完成配置。详见[外部工具](外部工具.md)。
- **配置外部工具…**：直接打开设置弹窗的「外部工具」页。
- **终止外部工具**：工具正在运行时停止它。
- **移入分组「名称」/ 新建分组并移入**：将未分组端口放入已有分组或新建分组。
- **移出分组**：将已分组端口放回「未分组」。
- **隐藏此串口 / 取消隐藏**：隐藏不常用端口，或在「更多操作 → 显示已隐藏串口」后将其恢复显示。

串口行本身没有“点击即连接”的行为；请使用右侧连接按钮、右键菜单或工具栏按钮。拖动时请抓住行左侧的拖动手柄，以免误触其它操作。

## 分组

分组头右侧的数字是「已连接数量 / 组内端口数量」。点击分组头可展开或折叠。右键分组头可执行：

- **连接整组 / 断开整组**：按顺序处理组内端口。
- **整组执行外部工具**：打开整组工具操作（见[外部工具](外部工具.md)）。
- **重命名分组**：也可以双击分组名称，在输入框中修改；按 Enter 确认，按 Esc 取消。
- **删除分组**：只删除分组，组内端口不会被删除，而会回到「未分组」。

把端口拖到分组头或组内端口上可移入该组；拖到另一个组可跨组移动；拖到「未分组」区域可移出分组。组内也可以拖动调整顺序。右键端口的分组菜单提供同样的移入/移出操作。

分组的名称、展开状态、成员及组内顺序会自动保存（通常在修改后短暂等待即可），不需要另找“保存布局”按钮。**未分组端口的排列顺序只影响当前会话，不保证下次启动保持**；端口号排序也不会变成持久的排序模式。

## 模拟端口（仅调试）

正式发布版不会显示模拟入口。调试版本中，可点击工具栏烧杯图标开启 `SIM:Loopback`，列表刷新后会出现该端口；再次点击可关闭模拟模式。关闭时会关闭模拟端口并从列表移除。

- 对 `SIM:Loopback` 发送普通文本时，如果内容去掉首尾空白后**完全是数字**，数字会被当作周期输出频率（次/秒）：例如发送 `10` 会请求每秒约 10 行，发送 `0` 停止周期输出。周期内容形如 `[SIM] Heartbeat #序号`，不会把这条数字当作普通回显内容。
- 其它普通文本会回显；HEX 发送和文件发送也可用于测试数据路径（文件发送在模拟端口上以 HEX 形式回显）。
- 模拟端口可用于没有真实硬件时测试连接、收发和终端显示，但不代表真实设备的时序或协议行为。

调试版本还可能显示终端图标。点击后会启动本机 Git Bash，列表出现 `GIT:BASH`；打开该端口后，在操作面板把模式切换为 **TTY 终端**，即可测试命令行交互。此功能需要安装 Git for Windows；没有 Git Bash 时启用会失败。它只在调试版本提供，正式版没有此入口。
