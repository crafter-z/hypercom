# 设置

点击标题栏的「设置」打开设置窗口。左侧提供：**通用设置、日志设置、备份管理、显示与交互、语法高亮规则、发送命令规则、协议解析、外部工具、条件触发、插件**。

普通设置改完后点击窗口底部「保存」；点击「取消」则放弃本次普通设置修改。规则页面里的规则集、命令集、协议模板和外部工具有各自的 ✓ 保存按钮；条件触发编辑会自动保存，底部「取消」不会撤销已经单独保存的规则。插件的安装、卸载、启用 / 禁用和权限更改也会立即持久化，不能用底部「取消」撤销；插件出站代理设置仍使用底部「保存」 / 「取消」。

## 通用设置

| 设置项 | 用途 |
| --- | --- |
| 程序关闭行为 | 选择关闭窗口时最小化到托盘，或直接退出程序。 |
| 最大显示行数 | 每个串口终端保留的最大行数（默认 100000）；超过后从最早的行开始移除。 |
| 语言 | 在简体中文和 English 之间切换。 |
| 主题 | 选择亮色、暗色或跟随系统。 |
| 防止系统息屏 / 防止系统休眠 | 勾选后，程序运行期间阻止屏幕关闭或系统休眠；关闭程序后恢复系统原设置。 |
| 启动时恢复上次会话 | 下次启动时恢复串口标签、允许恢复的插件标签和分屏布局；不自动连接串口，也不恢复插件解析历史或旧授权。 |
| 回车键插入换行 | 勾选后，按 Enter 在输入框中换行；未勾选时 Enter 发送。 |
| 字体设置 | 分别调整终端和界面字体及字号。 |
| 配置文件路径 | 查看当前配置文件位置，不能在此处直接编辑文件。 |

### 自动更新

- 选择**不自动检查**、定期检查**正式版**，或定期检查 **preview** 版；定期检查周期为 7 天。
- 发现更新后，可选择**立即更新**（显示下载进度）、**7 天后提醒**或**永不提醒**。选择「永不提醒」会同时关闭自动检查。
- 在「关于」窗口中可以手动选择检查正式版或 preview 版，不受自动检查开关影响。
- 更新窗口提供「更新日志」和「查看发布页」链接。下载期间窗口不能关闭；安装完成后程序会自动重启。

> preview 检查会比较正式版和 preview 中版本号较大的版本；preview 版本后续发布为正式版时，仍会正常识别为更新。

## 日志设置

在「日志设置」中设置自动保存、保存目录、文件名、分片、子目录、时间戳和收发方向等选项。详细说明见[日志记录](日志记录.md)的「日志设置」小节。修改后点击窗口底部「保存」使设置生效。

## 备份管理

### 配置导出 / 导入

- **导出配置**：通过保存对话框将应用设置、语法高亮规则、命令集和协议模板等配置保存为 JSON 文件。
- **导入配置**：通过打开对话框选择 JSON 文件；导入成功后应用会自动重新加载配置。

可用它备份自定义内容，或把设置迁移到另一台电脑。导入前建议先导出当前配置，避免覆盖现有设置。

配置备份包含插件的启用和授权状态，**不包含插件代码或插件私有数据**，不能用来安装插件或迁移其数据。只有仍为同一次安装的插件才能从备份恢复授权；升级、重装或换成不同代码后，即使插件 ID 相同，也需要重新审阅权限并启用。导入时，安装代次不匹配的插件会被禁用并清空授权；备份没有提到的当前插件保持原状。

### 日志备份选项

「备份管理」中的日志备份开关、周期和目录用于保存相关设置。需要备份日志时，请先在操作面板点「目录」，再用系统文件管理器复制日志文件或文件夹。

## 显示与交互

| 设置项 | 用途 |
| --- | --- |
| 预设波特率 | 设置串口参数中下拉列表显示的常用波特率。 |
| 显示串口类型（虚拟 / 真实） | 控制侧边栏是否显示串口类型标记。 |
| 默认换行方式 | 提供 CRLF、CR、LF 或不添加换行的选项；实际发送前请以发送区当前的「行尾」选择为准。 |
| 发送提示前缀 | 为终端中的发送行添加额外前缀；留空则不添加。 |
| 时间戳显示方式 | 选择每行显示，或每轮输出显示一个时间戳。 |
| 时间戳格式 | 选择绝对时间、相对时间或连接时长。 |

### 背景图

- 勾选**启用背景图**后，应用面板会半透明显示背景图片。
- 点击「浏览」选择 png、jpg、jpeg、bmp、webp 或 gif 图片；可设置不透明度（0–100%）和模糊度（0–64px）。
- 图片路径和效果会随设置保存。图片不可读取时不会影响其他功能；独立弹出窗口不共享主窗口的背景图。

## 插件

插件需要自行从可信来源获取，没有内置插件商店。插件运行第三方代码；权限和资源限制不是安全担保，请只安装并授权你信任的插件。

准备自行编写插件？请看独立的[插件开发指南](../plugin-development.md)；本节只介绍应用内操作。

### 安装、授权与运行

1. 在「设置 → 插件」点击「安装目录…」选择插件目录，或点击「安装 ZIP…」选择插件归档。使用安装按钮，不要直接替换应用保存的插件文件。
2. 新安装的插件默认**禁用且没有任何授权**。先阅读插件说明与权限列表，在未启用时勾选实际需要授予的权限；没有授予的能力不可使用。
3. 再点击「启用」，阅读并确认敏感权限提示。授权是信任决定：串口发送可向设备发出控制指令，网络访问可把数据发送给外部服务，剪贴板权限可能读取或改写剪贴板。只授予你理解用途的能力；确认提示不代表插件已经过安全审查。
4. 按插件说明使用其入口：插件可添加侧边栏按钮、端口右键菜单、串口内容视图及独立工作区标签，也可在主窗口底部的「插件输出」面板显示内容。只有插件产生输出后输出面板才会出现，可折叠查看；并非每个插件都会提供所有入口。插件仅在主窗口运行，独立弹出窗口不运行插件。

读取终端行的插件需要对应读取权限，并依赖 TRX 行数据；端口切到 TTY 时没有相同的行语义，行订阅会断开。没有看到预期内容时，先核对端口、显示模式、授权及插件说明，不要把 TTY 无行回调当作串口没有收到数据。

### 插件视图与工具标签

目前插件原生视图**仅实现 Windows 适配器**。其他平台会明确拒绝创建，不会改用主窗口嵌入网页；这不是已经完成跨平台或完整安全验收的声明。安装和授权仍须基于对插件来源的信任。

1. 按上面的步骤安装、授权并启用插件。视图需要 `ui:view`，读取输入还需它声明的相应权限（例如 `rx:bytes` 或 `terminal:read`）；插件通过自身按钮 / Worker 管理独立标签另需 `ui:tabs`。用户直接操作宿主的显示选择器或新标签入口，不额外要求 `ui:tabs`。
2. 打开要使用的串口标签，在内容区上方的「显示方式」选择「插件名：视图名」，即可用插件表格等替换原始终端内容。串口参数和连接不因选择视图而改变；只列出当前端口模式、授权和声明匹配的可用视图。
3. 若要保留原始终端，先选择「原始终端」，再在旁边的「在新标签中打开…」选择插件视图。新标签固定使用入口所在标签的明确端口，可以和原始终端同时查看；之后切换其他串口不会重绑它。
4. 无端口的设置页等工具通过主显示区「打开插件工具页…」打开，即使没有串口标签也可使用。插件也可能提供自己的侧边栏按钮或端口菜单入口，具体看插件说明。无端口工具页不是最近串口的替身，切到它时发送区不会沿用上一个串口作为目标。

- 标签标题旁和内容工具栏会标出插件来源；绑定端口的标签也会显示端口号。插件自定义表格和按钮来自第三方插件，不是应用内置功能。
- 同一插件、安装代次、视图、端口和实例键的重复打开会复用已有插件标签。宿主选择器与有效用户动作可以把它带到前台；后台请求不抢焦点。用户关闭后，插件不能用后台请求立即重开同一实例，但再次显式打开可以。
- 关闭额外插件标签不会关闭原始终端或其他视图，也不会断开串口；关闭原始串口标签不会停止仍打开的插件视图。需要停止设备连接时，请单独「断开」串口。开视图、恢复标签都不会自动连接设备。
- 禁用、撤权、升级、端口消失、模式不支持或运行出错时，独立插件标签保留错误占位，可「重试视图」或关闭；串口内的插件显示会回退原始终端并显示不可用提示，可重试或选择「原始终端」清除偏好。
- 串口的「显示方式」偏好会自动保存，独立于「启动时恢复上次会话」；额外插件标签只有插件声明允许恢复且开启该设置时才恢复。恢复保留布局与来源，不保留解析数据、旧操作令牌或打开参数，并重新检查安装代次与权限；升级、重装后旧标签不会替新代码恢复授权。
- 插件视图和独立插件标签不支持弹出窗口。需要弹出原始 TRX 终端时，先切回「原始终端」；TTY 仍不支持弹出。
- 原生视图允许真实用户操作的复制 / 剪切，但这不授予插件通用剪贴板权限，也不允许 UI 直接异步读取剪贴板；Worker 的剪贴板 API 仍按原有授权检查。

可运行的表格、波形与无端口设置页示例见 [Sensor Workspace](../../examples/plugin-views-demo/README.md)。

### 升级、停用与卸载

- **升级**：通过「安装目录…」或「安装 ZIP…」安装同一插件 ID、版本号严格高于已安装版本的新版；已安装时，相同或更低版本的安装尝试会被拒绝，不会建立新的安装代次。成功升级会建立新的安装代次，禁用插件并清空旧授权；重新审阅当前代码所需的权限后再启用，旧配置备份不能替新代码恢复授权。
- **禁用**：不再需要运行插件时点击「禁用」，保留已安装代码和私有数据。
- **卸载**：点击「卸载」并确认，会删除插件代码、配置授权和该插件私有数据。需要保留的信息应先使用插件自身提供的导出功能（如有）；应用配置导出不会备份这些数据。
- **重装**：先卸载后，可以重新安装任何有效版本（包括原版本），但卸载已删除的私有数据不会恢复。重装属于全新安装，会生成新的安装代次，仍需重新授权并启用。

### 代理与故障处理

插件出站网络默认不继承系统代理；需要代理时在本页显式配置并点击窗口底部「保存」。代理设置不会代替网络授权。

遇到安装、授权或运行错误，先保留错误信息并点击本页「刷新」读取当前状态；需要停止运行时使用「禁用」。若启动时发生中断恢复错误、列表与操作结果仍不一致，或错误反复出现，请从「关于 → 诊断日志」导出记录，附上插件来源、版本和操作步骤反馈。不要通过手动删除插件目录、私有数据或事务文件来尝试修复，以免丢失数据或破坏恢复依据。
