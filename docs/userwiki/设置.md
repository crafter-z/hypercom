# 设置

点击标题栏「设置」打开设置弹窗。左侧导航分为多个页面：**通用设置、显示与交互、日志设置、备份管理、语法高亮规则、发送命令规则、协议解析、外部工具、条件触发**。除规则页外，本页说明通用/显示/日志/备份与自动更新。

## 通用设置

| 设置项 | 说明 |
| --- | --- |
| 程序关闭行为 | 最小化到托盘 / 直接退出 |
| 最大显示行数 | 每个串口终端最多保留的行数（默认 100000），超过后最早的行被逐行顶掉 |
| 语言 | 简体中文 / English |
| 主题 | 亮色 / 暗色 / 跟随系统 |
| 防止系统息屏 | 运行时阻止屏幕关闭 |
| 防止系统休眠 | 运行时阻止系统睡眠 |
| 启动时恢复上次会话 | 重启后恢复上次的标签页与分屏布局 |
| 回车键插入换行 | 改变 Enter 行为（默认 Enter 发送） |
| 字体设置 | 终端字体、UI 字体及字号 |
| 配置文件路径 | 显示当前 config.json 路径 |

### 自动更新

- 自动检查更新：`不自动检查` / 定期检查到**正式版**（每 7 天）/ 定期检查到 **preview** 版（每 7 天）。
- 发现更新时弹窗，可选择：**立即更新**（带进度）/ **7 天后提醒** / **永不提醒**（同步关闭自动检查）。
- 在「关于」对话框里可**手动检查正式版 / preview 更新**（不受自动检查开关限制）。
- 更新弹窗可查看 **更新日志** 与 **查看发布页** 链接。
- 下载中弹窗不可关闭。安装完成后自动重启应用。

> Preview 通道检查的是 `正式版 vs preview` 中**版本号更大**的一个，preview 用户收尾后会自动晋升正式版。

## 显示与交互

| 设置项 | 说明 |
| --- | --- |
| 预设波特率 | 输入框中各档常用波特率 |
| 显示串口类型 (虚拟/真实) | 侧边栏是否显示类型徽标 |
| 默认换行方式 | 新建会话默认的行尾（CRLF / CR / LF / 无） |
| 发送提示前缀 | 留空为默认；可给 TX 行附加前缀 |
| 时间戳显示方式 | 每行 / 每轮输出一个时间戳 |
| 时间戳格式 | 绝对时间 / 相对时间 / 连接时长 |

### 背景图（毛玻璃）

- **启用背景图**：各面板半透明，露出全局背景。
- **背景图片**：选择一张图片（png/jpg/jpeg/bmp/webp/gif/svg）。
- **不透明度** / **模糊度**：0–100% 与 0–64px。
- 启用后整个应用呈毛玻璃效果。（独立的弹出窗是单独 webview，不共用背景层。）

> 背景图路径保存在配置里；每次启动读取图片并作为 data URL 渲染（不走 asset protocol）。

## 日志设置

见 [日志记录](日志记录.md) 页的「日志设置」小节——包含自动保存、存储目录、文件名格式、分片、子目录、方向/时间戳前缀等。

## 备份管理

### 日志备份

| 设置项 | 说明 |
| --- | --- |
| 开启日志库备份 | 周期性备份日志 |
| 备份周期 (小时) | 备份间隔 |
| 备份存储目录 | 备份存放路径 |

### 配置导出 / 导入

- **导出配置**：把应用配置、高亮规则、命令集与协议模板导出为 JSON 文件。
- **导入配置**：从 JSON 文件导入，导入后自动重载应用。

> 用于迁移/备份自定义规则，或在不同电脑间同步配置。

## 诊断日志

「关于 → 诊断日志」。用于排查应用自身问题：

- 启用诊断日志（随配置 `diagLogEnabled`）。
- 级别过滤、自动刷新、刷新。
- **导出** / **清空**。
- 查看后端与前端（`console.*`）统一落盘的诊断日志，可导出给开发者。
