# 设置

点击标题栏的「设置」打开设置窗口。左侧依次提供：**通用设置、日志设置、备份管理、显示与交互、语法高亮规则、发送命令规则、协议解析、外部工具、条件触发**。

普通设置改完后点击窗口底部「保存」；点击「取消」则放弃本次普通设置修改。规则页面里的规则集、命令集、协议模板和外部工具有各自的 ✓ 保存按钮；条件触发编辑会自动保存，底部「取消」不会撤销已经单独保存的规则。

## 通用设置

| 设置项 | 用途 |
| --- | --- |
| 程序关闭行为 | 选择关闭窗口时最小化到托盘，或直接退出程序。 |
| 最大显示行数 | 每个串口终端保留的最大行数（默认 100000）；超过后从最早的行开始移除。 |
| 语言 | 在简体中文和 English 之间切换。 |
| 主题 | 选择亮色、暗色或跟随系统。 |
| 防止系统息屏 / 防止系统休眠 | 勾选后，程序运行期间阻止屏幕关闭或系统休眠；关闭程序后恢复系统原设置。 |
| 启动时恢复上次会话 | 下次启动时恢复上次的标签页和分屏布局。 |
| 回车键插入换行 | 勾选后，按 Enter 在输入框中换行；未勾选时 Enter 发送。 |
| 字体设置 | 分别调整终端和界面字体及字号。 |
| 配置文件路径 | 查看当前配置文件位置，不能在此处直接编辑文件。 |

### 自动更新

- 选择**不自动检查**、定期检查**正式版**，或定期检查 **preview** 版；定期检查周期为 7 天。
- 发现更新后，可选择**立即更新**（显示下载进度）、**7 天后提醒**或**永不提醒**。选择「永不提醒」会同时关闭自动检查。
- 在「关于」窗口中可以手动选择检查正式版或 preview 版，不受自动检查开关影响。
- 更新窗口提供「更新日志」和「查看发布页」链接。下载期间窗口不能关闭；安装完成后程序会自动重启。

> preview 检查会比较正式版和 preview 中版本号较大的版本；preview 版本后续发布为正式版时，仍会正常识别为更新。

## 日志设置

在「日志设置」中设置自动保存、保存目录、文件名、分片、子目录、时间戳和收发方向等选项。详细说明见[日志记录](日志记录.md)的「日志设置」小节。修改后点击窗口底部「保存」使设置生效。

## 备份管理

### 配置导出 / 导入

- **导出配置**：通过保存对话框将应用设置、语法高亮规则、命令集和协议模板等配置保存为 JSON 文件。
- **导入配置**：通过打开对话框选择 JSON 文件；导入成功后应用会自动重新加载配置。

可用它备份自定义内容，或把设置迁移到另一台电脑。导入前建议先导出当前配置，避免覆盖现有设置。

### 日志备份选项

「备份管理」中的日志备份开关、周期和目录用于保存相关设置。需要备份日志时，请先在操作面板点「目录」，再用系统文件管理器复制日志文件或文件夹。

## 显示与交互

| 设置项 | 用途 |
| --- | --- |
| 预设波特率 | 设置串口参数中下拉列表显示的常用波特率。 |
| 显示串口类型（虚拟 / 真实） | 控制侧边栏是否显示串口类型标记。 |
| 默认换行方式 | 提供 CRLF、CR、LF 或不添加换行的选项；实际发送前请以发送区当前的「行尾」选择为准。 |
| 发送提示前缀 | 为终端中的发送行添加额外前缀；留空则不添加。 |
| 时间戳显示方式 | 选择每行显示，或每轮输出显示一个时间戳。 |
| 时间戳格式 | 选择绝对时间、相对时间或连接时长。 |

### 背景图

- 勾选**启用背景图**后，应用面板会半透明显示背景图片。
- 点击「浏览」选择 png、jpg、jpeg、bmp、webp 或 gif 图片；可设置不透明度（0–100%）和模糊度（0–64px）。
- 图片路径和效果会随设置保存。图片不可读取时不会影响其他功能；独立弹出窗口不共享主窗口的背景图。

## 诊断日志

在「关于 → 诊断日志」中可启用或停用诊断日志、筛选级别、刷新、导出或清空。它记录应用自身的前端和后端问题；遇到故障时可将导出的文件提供给开发者。
