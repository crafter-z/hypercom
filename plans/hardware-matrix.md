## 执行说明

1. 每种芯片至少准备 1 个设备，推荐 2 个（用于多端口并发测试）
2. 测试前在设备管理器确认驱动正常、COM 口号已分配
3. 高波特率测试需要硬件支持（部分 CH340 模块不支持 > 921600）
4. 热插拔测试：直接物理拔线，不要通过设备管理器禁用（那是另一项）
5. 压测期间观察任务管理器中 HyperCom 进程的内存/CPU 曲线
6. 每项测试记录：通过/失败/异常现象 + 截图（如适用）

## 已知 serialport-rs Windows 问题

- `serialport-rs` 在 Windows 上使用 `CreateFile` + `OVERLAPPED` I/O
- 部分 CH340 驱动版本（< 3.4）在高波特率下存在缓冲区溢出
- PL2303 在 Windows 11 22H2+ 需要 Prolific 官方驱动（微软商店版）
- USB 热插拔检测依赖 `WM_DEVICECHANGE` 消息，Tauri WebView2 窗口需保持消息循环
