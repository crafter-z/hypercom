# 任务目标
要使用Tauri技术架构实现“现代化 UI”+“复杂功能”+“高性能日志存储” 的串口调试工具

### 一、 技术架构：基于 Tauri 的现代化方案

考虑到串口通信对数据实时性和日志处理的要求，使用 **Rust 处理底层逻辑（性能） + 前端处理交互（颜值）** 的架构。

#### 1. 系统逻辑分层

* **UI 层 (Frontend):** 建议使用 **React/Next.js** 或 **Vue3** + **Tailwind CSS** + **Shadcn/UI**。
* 负责：串口配置界面、自定义命令列表、日志渲染（虚拟滚动）、字体缩放、主题切换。

* **核心逻辑层 (Rust Backend):**
* **Serial Manager:** 处理串口搜索、打开/关闭、波特率切换。
* **Data Hub:** 使用 Rust 的多线程（MPSC channel）处理接收到的原始字节流，避免大量数据涌入导致 UI 挂起。
* **Parser:** 负责 Hex/ASCII 转换及协议解析。

* **存储层 (Storage):**
* **SQLite/DuckDB:** 用于存储“自定义命令组”和“历史记录”。
* **Log Files:** 直接以追加模式写入本地 `.log` 文件。

#### 2. 关键功能实现思路

| 功能模块 | 实现策略 |
| --- | --- |
| **串口格式调整** | Rust 后端使用枚举映射 `DataBits`, `StopBits`, `Parity`，前端通过下拉框下发 Command。 |
| **日志存储** | 采用 **BufWriter** 异步写入，支持按日期或大小自动分片，避免占用过多内存。 |
| **自定义命令组** | 前端维护一个 JSON 配置，支持拖拽排序（推荐用 `dnd-kit`），支持一键导入/导出。 |
| **字体/UI 调整** | 利用 CSS 变量（Variables）全局控制。前端滑块调整 `--terminal-font-size` 即可实时预览。 |
| **数据实时显示** | **关键点：** 串口高频发送时，不要每次都更新 UI。Rust 侧进行 50ms-100ms 的节流（Throttling），打包后再发送给前端。 |

---

### 3、 为什么这套架构能胜任？

1. **内存安全：** 串口通信中常见的缓冲区溢出在 Rust 中能得到极大程度的规避。
2. **UI 渲染分离：** 即使串口数据以 115200 波特率满载发送，Rust 在后台处理解析和落盘，前端只负责渲染可见区域（通过虚拟列表），工具绝不会卡死。
3. **现代化体验：** 借助 Web 生态，你可以轻松实现“代码高亮（Hex 高亮）”、“命令自动补全”等 SSCOM 难以企及的功能。

### 4、 技术栈路线图 (Tech Stack)

* **框架:** [Tauri v2](https://v2.tauri.app/)
* **前端:** React + Vite + Lucide-react (图标)
* **状态管理:** Zustand (轻量，适合管理串口连接状态)
* **底层:** [serialport-rs](https://github.com/serialport/serialport-rs)

# 具体需求
## 一、 日志管理模块
1. 需要支持设置日志目录，选择日志在什么位置进行存储
2. 需要支持日志按照字符串、二进制、十六进制格式存储，按字符串格式存储时，支持存储时选择ASCII字符或UTF-8格式
3. 自动保存的日志需要支持设置文件名格式，默认按照\[com口\]-\[日期时间\]的格式进行存储。
4. 需要支持将当前串口窗口内的内容手动另存日志

## 二、 配置管理模块
1. 需要使用一个设置页面统一进行所有可配置项的配置管理
2. 需要支持的可配置项按大类进行整理，包括如下内容：
   1. 程序关闭后是最小化还是直接关闭
   2. 自动存储的日志是否开启分片存储，如开启分片存储，每到达多少MB后创建一个新的日志文件继续存储
   3. 串口主窗口中显示的实时串口输出最多运行占用多少内存，默认1024MB
   4. 语言
   5. 是否开启日志库备份，如开启，支持设置备份周期和备份存储位置
   6. 是否开启防止系统息屏的设置和是否开启防止系统休眠的设置
   7. 预设的多档波特率。主窗口中使用选项卡选择预设的波特率，波特率在配置页中添加或删除。
   8. 显示串口类型（虚拟串口或真实串口）
   9. 向串口发送内容时，回车按“\r\n”、“\r”、“\n”中的哪种方式换行
   10. 当向串口发送内容时，在主串口显示窗口及日志中应该打印什么提示前缀，默认为>>>>>>SEND>>>>>>>>
   11. 是否开启自动保存日志，如开启，支持设置日志的保存路径
   12. 保存日志的时候支持设置默认文件名格式
   13. 支持设置主串口窗口中的语法高亮规则，可以将多条规则聚合为一个规则集，一个规则集中可以设置多条按正则表达式或关键词规则高亮，高亮为可选的颜色或加粗、斜体，可以同时启用多个规则集
   14. 支持设置字体，可以区分主串口显示窗口和UI字体
   15. 支持设置背景图片
   16. 设置发送命令规则集，与语法高亮规则集类似，可以在一个规则集中添加多条发送命令，为每个命令设置顺序、名称、延时、发送类型（字符串、HEX、带不带回车）、命令内容。
   17. 设置主题，支持亮色或暗色或跟随系统
   18. 设置时间戳显示方式，对主串口显示窗口及日志中的时间戳，是采用每行显示一个时间戳的方式还是串口每轮输出显示一个时间戳

## 三、 串口管理模块
1. 将所有可用的串口罗列出来，以垂直选项卡的模式展示，支持拖动改变排序
2. 支持串口选项卡右键设置备注名
3. 选项卡以绿色标识未连接，黄色标识串口连接报错，红色标识已成功连接
4. 串口选项卡可以右键隐藏
5. 串口选项可以右键打开
6. 串口选项卡的后面有一个打开或关闭的小按钮，除此之外可以双击打开。打开时即连接对应的串口，同时在主串口窗口中打开对应的标签页；按下关闭时即断开与对应串口的连接，同时关闭主串口窗口中对应的标签页
7. 串口选项卡双击或右键可以唤起主串口窗口中对应的标签页，标签页开启或关闭不影响串口的连接。如果串口打开但对应的标签页关掉了，串口输出会吐到日志里
8. 支持串口选项卡聚合为一个选项卡组，像Edge浏览器的选项卡分组一样。一组选项卡组可以重新命名，可以一键开启或关闭整组选项卡组的串口。
9. 可以刷新串口选项卡，重新加载现有的系统串口

## 四、UI
1. UI划分为几个区域：标题栏、串口选项卡区、主串口显示窗口区、操作区、底部状态栏
2. 串口选项卡区除支持串口管理模块中所提到的功能需求外，还需要添加几个按钮，支持一键打开、关闭所有串口，支持显示隐藏的串口，支持按串口号一键排序选项卡，支持保存当前选项卡布局
3. 主串口显示窗口区用来显示串口的输入与输出，需要支持以下功能：
   1. 按浏览器标签页的逻辑来操作每个标签页。每个串口选项卡都有一个对应的标签页。
   2. 标签页选项卡上面可以支持关闭当前选项卡、关闭右侧选项卡、关闭左侧选项卡、关闭其他选项卡、固定选项卡
   3. 选项卡支持拖拽排序
   4. 显示区支持像VSCode或各种终端应用一样分屏，需要分屏足够灵活，可以左右分屏或上下分屏
   5. 分屏时会移动对应的选项卡，也就是说显示区内，一个串口对应的选项卡只会存在一个，分屏后会移动而不是复制。
   6. 分屏分走的选项卡可以像VSCode一样支持通过拖动拖至其他的分屏栏
   7. 选项卡内由于是串口输出，所以内容是只读的，不可以修改
   8. 有较丰富的右键菜单，除基本的全选、复制等基本文字操作外，可以将字符串转换为HEX或反向转换回来
   9. 支持选择编码（UTF-8或ASCII或其他），默认ASCII
4.  操作区是对串口进行交互操作的主要区域，需要支持以下功能：
   1. 打开或关闭当前串口
   2. 清屏
   3. 是否固定输出内容（当串口持续输出时，是跟随滚动，保持显示最新内容，还是用户可以自由操作，不会被新输出的内容强制拽下去）
   4. 打开日志所在的文件
   5. 使用默认程序打开日志对应的文件
   6. 是否显示时间戳
   7. 操作区使用HEX还是字符串输出
   8. 日志另存
   9. 波特率选择
   10. 数据位选择（5.6.7.8）
   11. 串口校验位选择（Even、Odd、Mark、Space、None）
   12. 停止位（One、Two、One Point Five）
   13. DTR开关
   14. RTS开关
   15. 是否忽略空字符
   16. 握手协议（XonXOff、RequestToSend、RequestToSendXonXOff）
   17. 高亮规则选择
   18. 编辑发送命令，跳转至设置窗口中的对应设置
   19. 开始按设定的延时循环发送选中的命令规则集中的命令，以及对应的停止按钮
   20. 当开始发送时，根据设定的规则集中的内容，每隔对应的时延后发送下一条命令。
   21. 命令发送区，主要用来手动向串口中发送内容：
       1. 支持设置按发送按钮时是否追加发送回车
       2. 支持设置按HEX格式发送还是按字符串发送
       3. 输入框
       4. 发送按钮
5.  底部状态栏显示当前的系统状态及串口状态，显示系统资源（内存、CPU占用率、TX数据总数、RX数据总数等）


# UI具体描述
这款软件的 UI 整体布局采用了现代桌面应用程序的经典结构，类似于 IDE 或高级终端，分为左侧边栏、中部多标签页显示区、右侧操作面板、标题栏和底部状态栏。它旨在同时管理和显示多个串口，并提供丰富的日志和发送功能。

### 串口工具 UI 规划设计描述（底部操作区版）

#### 一、 整体架构与区域
整个软件界面采用经典的 IDE 风格布局，自上而下、自左而右划分为以下几个主要区域：
1.  **标题栏 (Title Bar):** 位于最顶部，包含软件图标、名称、全局“配置”按钮以及窗口控制按钮。
2.  **左侧：串口选项卡区 (Left Sidebar):** 垂直侧边栏，用于统一管理和调度所有可用串口。
3.  **中上部：主串口显示窗口区 (Main Display Area):** 占据界面的核心位置，多标签页结构，用于显示串口通信内容。
4.  **中下部：操作区 (Bottom Operation Panel):** 位于主显示区正下方，呈横向布局，包含对当前选中串口的所有实时交互控制。
5.  **最底部：状态栏 (Status Bar):** 贯穿底部边缘，显示系统及通信的实时数据。
6.  **配置页面 (Configuration Window):** 独立的模态弹窗，通过标题栏唤起。

---

#### 二、 各模块 UI 详细描述

##### 1. 左侧：串口选项卡区
* **顶部工具栏:** 横排的小图标按钮组：一键打开全部、一键关闭全部、显示/隐藏串口、按端口号排序、保存布局、刷新系统串口。
* **串口列表:** 支持垂直滚动，可拖拽改变排序。
    * **组管理:** 支持将串口聚合成组（类似 Edge 浏览器选项卡组），可重命名，带展开/折叠箭头，并有一键开启/关闭整组的快捷按钮。
    * **单个串口项:** 包含状态颜色条（绿-未连接，黄-报错，红-已连接）、COM口及备注名（支持右键设置）、以及一个独立的连接/断开小按钮。
    * **交互逻辑:** 双击或右键唤起主窗口对应标签页；右键菜单包含：设置备注、隐藏/显示、打开/关闭。

##### 2. 中上部：主串口显示窗口区
* **标签页系统:**
    * 每个串口对应一个标签，标签上显示图标、COM口和备注。
    * 支持拖拽排序；右键菜单支持：关闭当前/左侧/右侧/其他、固定选项卡。
    * **灵活分屏:** 区域右上角提供分屏按钮，支持上下或左右分屏。分屏时标签页移动而非复制，支持在不同分屏间拖动标签。
* **内容显示区 (只读):**
    * 显示串口输入输出内容，根据配置好的规则集自动应用语法高亮。
    * **右键菜单:** 包含全选、复制、字符串与 HEX 相互转换。
    * **编码切换:** 右上角或右键菜单提供编码选择（默认 ASCII，可选 UTF-8 等）。

##### 3. 中下部：操作区 (横向布局)
为了充分利用底部横向空间，该区域在视觉上划分为左、中、右三个区块，所有操作均针对**当前主窗口选中的标签页（串口）**生效：

* **左侧区块：手动发送与基础控制**
    * **命令发送区:** 占据左侧主要宽度。包含输入框、显眼的“发送”按钮。
    * **发送选项:** 输入框下方或旁边排列单选/复选框：`[ ] HEX` / `[ ] 字符串`，以及“追加回车”下拉菜单（None, \r\n, \r, \n）。
    * **基础控制按钮:** `[打开/关闭当前串口]` `[清屏]`。
* **中间区块：自动循环与规则应用**
    * **快捷选择卡:** “高亮规则”下拉菜单、“发送命令集”下拉菜单，以及旁边的 `[编辑]` 按钮（点击跳转至全局配置页对应位置）。
    * **循环发送控制:** `[开始循环发送]` 按钮、`[停止]` 按钮、时延输入框 `[____] ms`。
* **右侧区块：串口参数与视图控制**
    * **视图与日志控制:** `[ ] 滚动锁定(固定输出)` `[ ] 显示时间戳` `操作区显示: [ ] HEX / [ ] 字符串`；日志操作：`[另存为...]` `[打开文件]` `[打开所在目录]`。
    * **串口参数 (紧凑型下拉/复选):** 波特率（调用预设）、数据位 (5-8)、校验位、停止位、握手协议；以及 `[ ] DTR` `[ ] RTS` `[ ] 忽略空字符` 开关。*(注：这部分可通过折叠面板或紧凑排版以节省空间)*。

##### 4. 最底部：状态栏
* **左侧:** 系统状态（如“运行正常”）、内存占用（如 150MB / 限制 1024MB）、CPU占用率。
* **右侧:** 当前串口实时流量统计（TX 总数、RX 总数，单位 Bytes/KB/MB 动态切换）。

##### 5. 独立配置管理页面
采用左侧树状导航，右侧详细设置的经典结构：
* **通用设置:** 关闭行为（最小化/退出）、内存占用上限、语言、防息屏/防休眠、主题（亮/暗/跟随系统）、主窗口与 UI 字体独立设置、背景图片。
* **日志设置:** 存储目录、文件名格式（默认 `[com口]-[日期时间]`）、编码格式（ASCII/UTF-8）、文件格式（字符串/二进制/HEX）、分片存储大小、自动保存开关。
* **备份管理:** 日志库备份开关、备份周期、备份路径。
* **显示与交互:** 预设波特率列表管理、显示串口类型开关（虚拟/真实）、回车换行方式设置、打印前缀设置、时间戳显示方式（按行/按轮）。
* **规则引擎 (高级):**
    * **语法高亮规则集:** 聚合管理，支持正则/关键词，可定义颜色/加粗/斜体，支持多规则集同时启用。
    * **发送命令规则集:** 支持添加多条命令，设定顺序、名称、延时、类型（字符串/HEX/回车状态）、具体内容。
