# Sensor Workspace：隔离视图与工作区标签示例

本例用一个业务 Worker 驱动传感器表格、温度波形和无端口设置页。插件 ID 为 `com.example.sensor-views`，声明见 [manifest.json](<manifest.json>)，解析与宿主调用见 [main.js](<main.js>)。可直接安装本目录，不需要先构建 UI。

**原生插件视图当前仅支持 Windows**，宿主须支持 `isolated-tab-view@1` 与 `plugin-workspace-tabs@1`。其他平台拒绝创建视图，不降级为主窗口嵌入网页。本例不能代替安全或跨平台验收；只安装你信任的代码。

## 安装、权限与更新代码

1. 在「设置 → 插件」选择「安装目录…」，选择本目录。也可按[打包说明](<../../docs/plugin-development.md#打包与升级>)打成 ZIP 后安装。
2. 初次安装默认禁用且未授权，阅读代码后按需要授予权限：

   | 权限 | 本例用途 |
   | --- | --- |
   | `ui:view` | 创建表格、波形与设置视图。 |
   | `rx:bytes` | 接收绑定端口的原始 RX 字节，供表格和波形解析。 |
   | `ui:tabs` | Worker 响应按钮、菜单和表格动作，打开独立插件标签。 |
   | `storage` | 设置页通过 Worker 读写私有 KV 中的 `threshold`。 |
3. 可在安装后的确认框选择「授予全部并启用」，也可稍后在设置页逐项授权并启用。
4. 用户通过宿主视图选择器或标签栏 `+` 创建视图，不额外要求 `ui:tabs`，但仍需视图及输入权限；本例由 Worker 打开的按钮、菜单和表格动作需要 `ui:tabs`。

修改源文件后，重新选择本目录安装才能更新已安装副本。同版本或降级安装需要额外确认替换；更新保留私有数据，但重置授权和网页信任，需重新审阅。不要为更新代码先卸载，卸载会删除私有数据。宿主的开发热更新不会同步已安装插件；「重载已安装代码」只重启已安装副本，不重新复制源目录。完整说明见[安装、调试与重载](<../../docs/plugin-development.md#本地调试>)。

本例不申请串口发送、网络、文件或剪贴板权限；测试输入由用户通过宿主发送区或外部设备产生。

## 表格与输入格式

1. 打开一个串口标签，配置参数并由用户单独连接。**打开插件视图不会自动连接端口。**
2. 在串口内容区的视图选择器中选择「Sensor Workspace: Sensor table」，可用表格替换终端显示。表格接收原始字节，TRX 和 TTY 都可使用。
3. 如需保留原终端，点击标签栏 `+` 选择 **Sensor table**，或在端口菜单选择 **Open sensor table**，打开绑定当前端口的独立表格标签。

表格提供设备名子串过滤、按时间或温度或电压降序排列、清空当前会话、阈值高亮及打开波形按钮。状态行显示端口、连接状态、记录数、输入间断次数 `gaps` 与拒绝次数 `rejected`。

每个表格或波形会话最多保留 200 条有效记录，不共享历史。非空非法行计入 `rejected`；单次输入拼接后的待解析文本超过 8192 个字符时，该缓冲被丢弃并计一次拒绝。输入不连续时清空半帧、重建 UTF-8 解码器并累计 `gaps`，避免拼接断线前后的数据。

### 传感器帧

设备发送 UTF-8 文本，每帧以 LF（`\n`）结束，也接受 CRLF：

```text
S,<device>,<temp>,<volt>*<xor2hex>
```

- `device` 非空且不含逗号，建议用 ASCII 名称以避免设备端校验编码歧义。
- `temp` 与 `volt` 是整数或普通小数，可带负号，不接受指数写法。
- `xor2hex` 是从首字符 `S` 到 `*` 前最后一个字符逐字符异或的结果，用两位十六进制表示；不包含 `*`、校验字段和换行符。

例如，正文 `S,probe,25.0,3.3` 的校验是 `22`。在宿主发送区输入以下正文，并把行尾选为 LF；不要发送字面字符 `\n`：

```text
S,probe,25.0,3.3*22
```

### 无硬件演示（仅调试版本）

Windows 调试版本可开启、打开并连接 `SIM:Loopback`，再通过宿主发送区发送 `10` 请求每秒约 10 行心跳，发送 `0` 停止。发布版本没有该模拟端口入口，具体步骤见[模拟端口](<../../docs/userwiki/串口管理.md#模拟端口仅调试>)。

Worker 也接受以下模拟行，不要求传感器校验：

```text
[SIM] Heartbeat #42
```

序号会被映射为设备名 `SIM`、温度 `25 + sin(sequence / 10) × 8` °C 和电压 `3.3 + cos(sequence / 8) × 0.1` V。这些是合成值，不是设备测量，与传感器帧共用会话记录上限。

## 波形与时间联动

- 表格的 **Open waveform tab** 在后台打开同一端口的波形，表格保持前台；端口菜单 **Open sensor waveform** 可前台打开。不同入口使用默认实例键，重复打开复用同一页面。
- 表格和波形从各自打开后的新输入开始解析；后台视图继续消费输入。关闭一个插件标签不关闭同端口的其他视图或物理连接。
- 表格与波形可通过 `view.timeline` 参与时间联动。记录时间来自完成该帧的输入块时间戳，不把插件处理时刻伪装成采集时间；未知时间显示「—」。
- 表格只在当前过滤结果中定位，**Align by this time** 才是主动驱动操作；按温度或电压排序时不能驱动，但仍可跟随。波形按输入记录时间绘制，时间滑杆在释放、取消或失焦时结束导航。
- 本例只有有界的小记录集，不能作为百万条图表的索引实现模板。过滤、裁剪、无时间或超出范围都会报告结果；联动不补历史、不发送串口数据，也不修改记录原始时间。

时间请求和结果使用独立通道，不由业务状态回调确认；本例在绘制后检查取消信号再报告结果。完整契约见[时间联动 API](<../../docs/plugin-development.md#可选时间联动-apiui-专用>)。

### 单独安装无 Worker 时间页

[workerless manifest](<workerless/manifest.json>)和[时间页](<workerless/index.html>)组成另一个独立插件包。在「安装目录…」选择 `workerless/`，授予 `ui:view` 并单独确认可信网页信任，再从宿主 `+` 打开 **Custom device clock**。

该页不需要端口、Worker 或业务状态，使用固定的 1000–6000 ms 样本和自定义时钟。与其他采集源比较前必须在宿主确认时间映射，不能当成宿主时钟；它不发网络请求，但仍受可信网页的能力和信任边界约束。

## 无端口设置页与私有数据

标签栏 `+` 的 **Sensor settings** 与侧边栏同名按钮复用同一设置页，无需串口。表格则需要明确端口，不会借用上次活动端口。

设置页的 **Temperature alert threshold °C** 修改后点击 **Save**，Worker 将有效数值限制在 -100 到 200 之间，再保存到私有 KV 的 `threshold`。打开设置页时读取保存值，没有有效保存值则使用本次 Worker 默认的 30 °C；后续表格快照使用当前阈值高亮。保存阈值不会向设备发送命令。

配置备份不包含私有 KV；卸载会删除私有数据。

## 实现与使用边界

- [业务 Worker](<main.js>)负责解析、会话、KV 与标签调用；[表格](<ui/table.js>)、[波形](<ui/wave.js>)和[设置页](<ui/settings.js>)只通过 `view` SDK 渲染或提交消息，不直接调用 Tauri、串口、文件或网络。
- 真实用户复制或剪切不等于授予 Worker 通用剪贴板权限；插件标签和插件串口显示不支持弹出为独立窗口。
- 开启会话恢复后保存的是描述符与布局，不是解析历史或原生句柄。恢复仍需当前安装、授权与端口检查，不自动连接；升级或重装不能沿用旧授权。
- 插件独立标签不可用时保留错误占位，串口替换视图不可用时回退原始终端并提供原因和设置入口；按提示解决原因或关闭页面。

完整操作见[插件使用](<../../docs/userwiki/插件.md>)，作者接口见[插件开发指南](<../../docs/plugin-development.md>)，宿主标签行为见[工作区架构](<../../docs/architecture/workspace.md>)。
