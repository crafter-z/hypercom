# Sensor Workspace：隔离视图与工作区标签示例

这个插件演示同一业务 Worker 驱动三个独立原生 UI：传感器表格、温度波形，以及不绑定串口的设置工具页。插件 ID 是 `com.example.sensor-views`；入口和视图声明见 [manifest.json](manifest.json)，解析与宿主调用见 [main.js](main.js)。文件可直接按目录安装，不需要先打包 UI。

**当前原生视图仅实现 Windows 适配器**，需要支持 `isolated-tab-view@1` 与 `plugin-workspace-tabs@1` 的 HyperCom。其他平台明确拒绝创建视图，不降级为主窗口嵌入网页。示例不是完整安全验收或跨平台发布完成的证明；只安装你信任的插件。

## 安装与权限

1. 在「设置 → 插件」点击「安装目录…」，选择本目录（包含 `manifest.json`、`main.js` 与 `ui/`）。也可将这些文件按相同目录结构打成 ZIP 后使用「安装 ZIP…」。
2. 插件初装禁用且未授权。阅读代码与权限说明，再按需要授予以下权限：

   | 权限 | 本例用途 |
   | --- | --- |
   | `ui:view` | 创建声明的原生表格、波形与设置视图。 |
   | `rx:bytes` | 表格和波形解析所绑定端口的原始 RX 字节。 |
   | `ui:tabs` | Worker 响应插件按钮 / 菜单及表格动作，打开独立插件标签。 |
   | `storage` | 设置页通过 Worker 读写私有 KV 中的 `threshold`。 |

3. 点击「启用」并确认权限提示。安装、授权与启用操作立即持久化，不受设置窗口底部「取消」撤销。
4. 用户直接在宿主的「显示方式」「在新标签中打开…」「打开插件工具页…」创建视图只要求 `ui:view` 及相应输入权限，**不额外要求 `ui:tabs`**；但本例的插件菜单、侧边栏按钮和「Open waveform tab」经 Worker 调用 `tabs.open`，需要 `ui:tabs`。

本例不申请串口发送、网络、文件或剪贴板权限。需要产生测试输入时由用户操作宿主发送区或外部设备，而不是插件发送数据。

## 使用表格：替换串口显示或保留原始终端

1. 打开一个明确的串口标签，按设备要求配置参数，并由用户单独连接。**开插件视图不会自动连接端口**。
2. 在串口内容区顶部「显示方式」选择「Sensor Workspace: Sensor table」，表格替换原始终端的内容区。表格声明支持 TRX 和 TTY，使用字节输入而不是 TRX 行订阅；设备帧仍须带换行符。
3. 若想同时保留原始终端，选择「原始终端」，再在旁边「在新标签中打开…」选择「Sensor Workspace: Sensor table」。会创建固定绑定该端口的独立表格标签，不随之后的活动串口变化重绑。
4. 也可在侧边栏端口右键菜单选择 **Open sensor table**，由 Worker 使用这次宿主用户动作的令牌前台打开表格。

表格提供：

- **Filter device**：按设备名做不区分大小写的子串过滤。
- 排序选择：最新在前、温度降序、电压降序。
- **Clear**：只清空当前表格会话的记录，不清宿主终端历史，也不清另一波形会话。
- 温度达到阈值的行高亮；状态行显示绑定端口、连接状态、记录数、`gaps` 与 `rejected`。

每个表格 / 波形会话只保留最近 **200 条**有效记录，最早记录随新数据移除。非空非法行计入 `rejected`；未完成帧缓冲超过 8192 个字符时丢弃并计一次拒绝。输入不连续时重置 UTF-8 解码器与未完成帧，累计 `gaps`，不会把断线前后的半帧拼成一条记录。

## 输入格式

传感器发送 UTF-8 文本，每帧以 **LF (`\n`)** 结束（解析器也接受 CRLF）：

```text
S,<device>,<temp>,<volt>*<xor2hex>\n
```

- `device` 为非空、不含逗号的设备名；建议使用 ASCII 名称以避免设备端校验算法的编码歧义。
- `temp` 与 `volt` 是整数或普通小数，可带负号，例如 `25.0`、`3.3`、`-2.5`；不接受指数写法。
- `xor2hex` 是从首字符 `S` 到 `*` 前最后一个字符逐字符异或的结果，用两位十六进制表示，大小写都接受；不包含 `*`、校验字段或换行符。

例如，对正文 `S,probe,25.0,3.3` 异或得到 `22`，实际发送以下内容并附 LF：

```text
S,probe,25.0,3.3*22
```

上面的代码块展示正文，不是让设备发送字面字符 `\n`。在宿主发送区输入正文时，将行尾选为 LF。

### 无硬件演示：SIM Heartbeat（仅调试版本）

正式发布版没有模拟端口入口。Windows 调试版本中，可用侧边栏烧杯图标开启 `SIM:Loopback`，打开并连接它，然后通过宿主发送区发送普通文本 `10`，请求每秒约 10 行心跳；发送 `0` 停止。具体操作见[串口管理：模拟端口](../../docs/userwiki/串口管理.md#模拟端口仅调试)。

Worker 另外接受下面这种模拟行，不要求传感器 XOR 校验：

```text
[SIM] Heartbeat #42
```

它将序号映射为 `device = SIM` 的演示数据：温度 `25 + sin(sequence / 10) × 8` °C，电压 `3.3 + cos(sequence / 8) × 0.1` V。这些是示例合成值，不是实际设备测量。SIM 与真实传感器帧共用同一个 200 条上限。

## 波形标签与打开行为

- 表格中的 **Open waveform tab** 把 `open-wave` 消息发给 Worker；Worker 为同一绑定端口调用 `tabs.open({ viewId: 'wave', instanceKey: 'live', activation: 'background', ... })`。波形标签在后台打开，**表格保持前台**；手动点击新标签查看温度曲线。
- 端口右键菜单 **Open sensor waveform** 使用真实宿主操作令牌请求前台打开同一 `live` 波形实例。重复打开会复用已有标签，而不是不断新增。
- 去重键包含插件 ID、安装代次、视图 ID、绑定端口和 `instanceKey`。宿主「在新标签中打开…」使用默认实例键 `default`，插件菜单和表格动作使用 `live`；不同键可有各自独立会话。
- 前台打开需要宿主用户动作令牌，后台打开不需要令牌但不能抢焦点。关闭 `live` 波形后，同一后台动作不能立即把它重开；可用端口菜单的真实前台操作重新打开。
- 表格和波形分别从打开后的新输入开始解析，不共享历史记录；后台视图仍消费输入并保留有界状态，重新切到前台呈现当前快照。

## 无端口设置页与私有 KV

主显示区「打开插件工具页…」可选择「Sensor Workspace: Sensor settings」，无需先打开串口。也可点击插件侧边栏 **Sensor settings** 按钮，Worker 使用这次用户动作前台打开 `settings` 实例。

页面显示 **Temperature alert threshold °C**。修改后点击 **Save**，UI 发送 `save-threshold` 消息，Worker 把有效数值夹在 `-100` 到 `200` 范围内，再经 `storage.set` 写入插件私有 KV 的 `threshold`。设置页打开时经 `storage.get` 读取已保存值；未读取到有效保存值时本次 Worker 使用默认阈值 30 °C。后续表格快照使用 Worker 当前阈值做高亮。

工具页的 `portBinding` 是 `none`、`input` 是 `none`，不会隐式绑定当前或最近串口，Save 不向设备发送命令。配置备份不包含此私有 KV；卸载插件会删除私有数据。

## 生命周期与隔离边界

- `main.js` 在唯一业务 Worker 中做解析、维护各视图会话、调用 KV 与标签 API；`ui/table.js`、`ui/wave.js`、`ui/settings.js` 只通过 `view.onState`、`view.onEnvironment` 与 `view.send` 渲染或提交消息。
- UI 没有直接 Tauri / 原生 API，不自行读串口、文件、网络或异步剪贴板。真实用户复制 / 剪切允许，但不会因此给 Worker 增加通用剪贴板授权。
- 宿主显示插件来源和绑定端口；插件标签与生效中的插件串口显示不支持 popout。
- 关闭一个插件标签只释放它的会话；不关闭原始终端、同端口其他视图或物理连接。关闭原始串口标签也不停止仍打开的插件视图。
- 串口显示方式偏好保存到端口元数据，与会话恢复开关独立。本例三个视图都允许恢复；开启「启动时恢复上次会话」时，独立标签保存的是描述符和布局，不是解析记录、打开参数或原生句柄。恢复仍重新检查安装代次、授权和端口，也不会自动连接。
- 独立插件标签不可用时保留错误占位，可重试或关闭；串口替换视图不可用时回退原始终端并显示提示，可重试或切回原始终端清除偏好。升级 / 重装后需要重新审阅权限，旧描述符不能恢复新代码的授权。

完整操作说明见[设置：插件](../../docs/userwiki/设置.md#插件)，作者契约见[插件开发指南](../../docs/plugin-development.md)，宿主工作区模型见[工作区架构](../../docs/architecture/workspace.md)。
