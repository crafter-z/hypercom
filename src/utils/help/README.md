# Built-in Help content pipeline

- Source of truth: `docs/userwiki/*.md` and `docs/userwiki/images/`. Do not edit `generated.json` by hand.
- `scripts/build-help.mjs` / `ARTICLE_SOURCES` assigns permanent article IDs independently of Chinese titles and filenames. New pages must be registered there. Existing IDs are navigation identities; do not rename them when editing a title.
- `npm run help:build` compiles Markdown at build time with GFM support into the closed `HelpBlock` / `HelpInline` model. Both `npm run dev` and `npm run build` run it first. After editing a Wiki page during a running Vite session, rerun `npm run help:build`; Vite then reloads the generated JSON. No Markdown parser ships in the WebView.
- `npm run help:check` fails on stale generated content, missing/unregistered pages, invalid article IDs, broken links/anchors/images, remote images, unsupported/unsafe navigation, and non-regular resource files. `npm run test:help` runs compiler and runtime/renderer tests.
- `links.mjs` / `resolveHelpLink` is shared by the Node compiler and WebView. Internal links target article IDs and generated Unicode heading anchors. Outside the Wiki, only the four explicitly listed developer/reference documents become GitHub links, pinned to the package version's tag. They are not available offline; the Help UI must label external navigation and open it through its controlled shell service.
- `assets.ts` / `getHelpImageUrl` exposes only enumerated raster images through Vite's same-origin asset URLs. No arbitrary disk path, `file:`, data URL or network fetch is required.
- `HelpDocument` only creates React elements from the closed model. Raw Markdown HTML is displayed as text. Article links dispatch `onNavigate`, external links dispatch `onExternalLink`, and screenshot previews dispatch `onImage`; no article action invokes Tauri or changes a serial-port state.
- `helpCatalog` exposes local articles, lookup, text search and link resolution. `loadHelpArticle` is an async-compatible local lookup, not a network request. Article and UI locale are separate: current bundled content is Chinese (`zh-CN`), including when the application UI is English.
